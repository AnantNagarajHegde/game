# Movement and architecture review

Native Unity captures of the November 2026 polish pass, at 1920x1080.

- `movement.png`: the articulated player in motion, using a side camera for gait inspection. Normal gameplay retains its third-person camera.
- `tea-stall.png`: roof fascia, rafters, lime-plaster relief and framed kitchen doorway.
- `library.png`: timber joinery, dressed sill, stone foundation courses and veranda construction.
- `house.png`: building detail from the main village lane.

Run **Paridhwani > Review movement and architecture** to reproduce the physical-input and geometry review. The test uses a separate visit. Follow `../UI_GRAPHICS_TEMPLATE.md` for future changes. Verification results are recorded in `../../verification/movement-architecture-review.txt`.
